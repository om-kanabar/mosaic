# Mosaic: A Novel Data Augmentation Method for Reducing Overfitting in Time-Series Models
#### By: Om Kanabar
---

Basically for getting more data for limited time series data right now there are only a couple of options:

Running more experiments (expensive)
Randomly Augmenting (messes up data)
Gaussain Noise (proven to not be helpful)
Running a simulator (expensive and hard)

Mosaic will solve this for a couple of reasons:

1. It Will Be cheap to run since it is pretty lightweight
2. It will be easy to use current data to synthesize new data so it seems like everyhting is from the same dataset.
